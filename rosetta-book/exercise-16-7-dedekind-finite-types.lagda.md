## Problem statement

Consider a finite type `X`.

### Exercise 16.7(a)

Show that any embedding `f : X → X` is an equivalence.
Sets `X` such that every embedding `X ↪ X` is an equivalence are also called **Dedekind finite**.

### Exercise 16.7(b)

Show that any surjective map `f : X → X` is an equivalence.
