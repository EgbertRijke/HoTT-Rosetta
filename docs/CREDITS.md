# Website credits

This website uses the Agda HTML backend and mdBook, following the setup supplied
with [agda-unimath](https://unimath.github.io/agda-unimath/).

The mdBook theme, Agda styles, favicon assets, and highlighting generator were
copied or adapted from agda-unimath. Its MIT license notice is retained in
[LICENSE-agda-unimath.md](LICENSE-agda-unimath.md). This notice covers those
reused files; it does not assign a new license to Rosetta's book text or proofs.

The theme includes [Catppuccin](https://github.com/catppuccin/mdBook) color
schemes and [mdbook-pagetoc](https://github.com/slowsage/mdbook-pagetoc)
page navigation, as in agda-unimath.
